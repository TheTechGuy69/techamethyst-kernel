# TechAmethyst v1.1

`uname -r`: `6.1.138-android14-11-gef638e794666-TechAmethyst`

v1.1 was the first TechAmethyst kernel with root hiding. It was built with `scripts/techamethyst_setup.sh` (baseline)
and `scripts/techamethyst_features.sh` (features). There is no public binary release for v1.1; v1.2 replaces it
with the same features on a newer base. Source: the `v1.1` snapshot (tag `v1.1`) on the `kernel` branch.

## Base
- **android14-6.1-2025-06_r15**, commit `0c3d559bcd85`, Linux **6.1.138**, KMI generation 11.
- This is the exact commit of the stock kernel on the device (`6.1.138-android14-11-g0c3d559bcd85-ab14529422`, HyperOS 3.0.306).
- **Baseline check:** an unmodified build of this commit gave the **same version string and an identical `.config`** as the stock kernel.
  The bytes differ (timestamps and build paths), which is expected.

## Features (one commit on top of the base)
`KSU=1 SUSFS=1 BBR=1 NTFS3=1 WLBLOCK=1 TUNE=1 STATUS=1`

| Flag | What | Where |
|---|---|---|
| KSU | KernelSU-Next **v3.4.1** (version code 33345), built in, from the pershoot `dev-susfs` fork @ `956ea0f5` | `drivers/kernelsu/` |
| SUSFS | susfs4ksu **v2.3.0** (`gki-android14-6.1` @ `e0b6100` + pershoot dev commits `d510048`, `35b2a01`), SUS_PATH, SUS_MOUNT, SUS_KSTAT, SPOOF_UNAME, SPOOF_CMDLINE, SUS_MAP, OPEN_REDIRECT, log, symbol hiding | 24 files in `fs/`, `kernel/`, `mm/`, `security/selinux/`, `drivers/input/` + `fs/susfs.c` |
| BBR | TCP BBR as the default congestion control (fq is already built in) | `gki_defconfig` |
| NTFS3 | NTFS read/write for USB OTG drives (exFAT is already in GKI) | `gki_defconfig` |
| WLBLOCK | wakelock blocker: `/sys/module/wakeup/parameters/ta_ws_block` = `"name1;name2"` (empty = off) | `drivers/base/power/wakeup.c` |
| TUNE | `-mtune=cortex-a720` (scheduling only; no new instructions, no KMI effect) | `arch/arm64/Makefile` |
| STATUS | `/sys/kernel/techamethyst/{version,features}` | `kernel/techamethyst.c` |

Kleaf housekeeping, the same steps GKI custom-kernel CIs use:
- `check_defconfig` is removed from `build.config.gki`.
- `android/abi_gki_protected_exports_*` and the `protected_exports_list` entries in `BUILD.bazel` are removed.
  The kernel has its own module-signing key, so stock system_dlkm modules count as unsigned. They must still be able to use those exports.
- `scripts/setlocalversion`: `-dirty` is dropped and `-TechAmethyst` is appended.
- `build/kernel/kleaf/impl/stamp.bzl`: `-maybe-dirty` is dropped. This file is outside the kernel tree.

**susfs patch:** one hunk applied **with fuzz 2**: `fs/exec.c` #1, which adds the `susfs_def.h` include.
All other hunks were exact or offset-only. The result was checked: the include is placed correctly.

Config: MGLRU on (`LRU_GEN_ENABLED=y`), zram default `lzo-rle`. These are stock GKI settings and were left unchanged.

## Verified
- **KMI:** all 8142 symbols in `vmlinux.symvers` have the same CRC as the unmodified baseline build, with 0 changed and 0 missing.
  v1.1 used this CRC check only. The STG check and the `.ko` import gate were added in v1.2 and v1.3.
- **boot.img:** repacked from the device's own stock boot.img with only the kernel swapped.
  The AVB hash footer uses the same partition size (100663296) and props as stock, so the image can be flashed, not just booted.
- **AnyKernel3 zip:** made for flashing from the KernelSU manager or recovery.

## History
- **v1.0**: version string, official KernelSU-Next v3.4.1 built in, BBR, NTFS3, wakelock blocker. No SUSFS.
- **v1.1**: v1.0 plus SUSFS (via the pershoot KernelSU-Next fork), `-mtune`, the status node and the AnyKernel3 zip.

## Test plan (as used for v1.1)
1. Keep the stock `init_boot` (not a KernelSU-patched one): KernelSU is inside the kernel now.
2. `fastboot boot boot.img`: a one-time boot; a reboot returns to the installed kernel.
3. Check `uname -r` ends in `-TechAmethyst`, `su -c 'lsmod | wc -l'` matches stock, and touch, fingerprint, charging, Wi-Fi, data, camera and audio all work.
4. Only then `fastboot flash boot boot.img`. Rollback: flash your stock boot.img.
